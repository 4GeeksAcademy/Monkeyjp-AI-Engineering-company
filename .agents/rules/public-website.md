# Brasaland Public Website Rules

- Files under `uis/website/` represent the public Brasaland brand.
- Follow the public-website milestone context.
- Preserve the existing application stack unless migration is explicitly approved.
- Reuse repeated UI patterns where practical.
- Customer-facing content must remain accessible, responsive and business-accurate.
